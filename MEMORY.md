# MEMORY.md

Живые правила, которые всплыли по ходу разработки. Не дублировать `DECISIONS.md`: там архитектура (почему схема/стек такие), здесь — паттерны, которые иначе снова сломают.

Пишем только то, что повторяется или с высокой вероятностью повторится. Разовые баги сюда не кладём.

## Как добавлять

1. Агент **предлагает** правило в чате, не пишет его сам.
2. Правило короткое: что делать / чего не делать, и зачем.
3. Формат ниже. Статус `active`, пока правило не отменили.

```
## YYYY-MM-DD — короткое имя

**Status:** active

**Rule:** одно-два предложения.

**Why:** зачем это помнить.
```

## Правила

Пока пусто. Сюда попадают записи после предложения в чате и согласия.
